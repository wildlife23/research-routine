## 요일별 테마
- 월: 인간이 생각하기 힘든 질문 (AI, 우주, 의식, 존재의 경계)
- 화: AI 활용 능력 향상 (AI와 공존하는 미래를 위한 실천적 질문)
- 수: 약점 보완 (언어 표현, 대인관계, 소통)
- 목: 강점 심화 (자연 관찰, 공간적 사고, 논리·분석)
- 금: 철학·윤리 (정답 없는 질문, 자신의 입장 세우기)
- 토: 몸과 감각 (관찰, 묘사, 감각을 언어로 표현)
- 일: 관계·대화 (연결, 감사, 경청, 타인 이해)

## 질문 생성 원칙
1. 질문은 딱 하나. 짧고 선명하게.
2. 업무·연구와 직접 관련된 내용은 제외.
3. 이전에 생성된 질문과 절대 반복하지 말 것.
4. 정우의 배경과 성장 맥락을 은근히 반영하되
   노골적으로 드러내지 말 것.
5. 질문은 답이 있는 게 아니라 생각을 여는 것이어야 함.
